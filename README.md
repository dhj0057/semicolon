# 학교 동아리 활동 저장소

## 1. 소개

이 저장소는 학교 동아리 활동을 정리하고 공유하기 위한 공간입니다.
동아리에서 진행하는 업무, 공모전 준비, 게임 개발, 챗봇 개발, 웹페이지 제작 등 다양한 활동 내용을 기록합니다.

단순히 결과물만 저장하는 것이 아니라, 프로젝트를 진행하면서 배운 내용, 문제 해결 과정, 회의 내용, 역할 분담, 개발 기록 등을 함께 정리하는 것을 목표로 합니다.

---

## 2. 활동 목적

* 동아리 활동 내용을 체계적으로 정리
* 프로젝트별 진행 상황 공유
* 공모전 및 대외활동 준비 자료 관리
* 팀원 간 협업 방식 연습
* GitHub 사용 경험 쌓기
* 개발 결과물과 학습 과정을 포트폴리오로 정리

---

## 3. 주요 활동 분야

### 3-1. 동아리 업무 정리

동아리 운영에 필요한 기본 업무를 정리합니다.

* 회의록 작성
* 일정 관리
* 역할 분담
* 자료 조사
* 발표 자료 준비
* 활동 기록 정리
* 공지사항 및 전달사항 관리

---

### 3-2. 공모전 준비

공모전 참여를 위한 아이디어 기획, 자료 조사, 개발 계획 등을 정리합니다.

* 공모전 주제 분석
* 아이디어 회의
* 서비스 기획
* 기능 정의
* 개발 일정 작성
* 발표 자료 제작
* 결과물 정리

---

### 3-3. 게임 만들기

C언어, Java, Python 등을 활용하여 간단한 게임을 제작합니다.

예시 프로젝트:

* C언어 콘솔 게임
* 2차원 배열 기반 게임
* 폭탄 피하기 게임
* 낚시 미니게임
* 점수 계산 게임
* 랜덤 요소가 들어간 미니게임

학습 목표:

* 변수, 조건문, 반복문 이해
* 배열 활용
* 함수 분리 연습
* 게임 규칙 설계
* 사용자 입력 처리
* 코드 구조화 연습

---

### 3-4. 챗봇 만들기

AI API 또는 간단한 조건문 기반 로직을 활용하여 챗봇을 제작합니다.

예시 프로젝트:

* 건강 관리 챗봇
* 학습 도우미 챗봇
* FAQ 챗봇
* 상담형 챗봇
* 간단한 AI 응답 챗봇

학습 목표:

* 사용자 입력 처리
* 응답 로직 설계
* API 요청 및 응답 구조 이해
* 프론트엔드와 백엔드 연결
* 챗봇 서비스 흐름 이해

---

### 3-5. 웹페이지 만들기

HTML, CSS, JavaScript 등을 활용하여 웹페이지를 제작합니다.

예시 프로젝트:

* 동아리 소개 페이지
* 프로젝트 소개 페이지
* 개인 포트폴리오 페이지
* 건강 관리 웹페이지
* 공모전 서비스 소개 페이지
* 팀 프로젝트 랜딩 페이지

학습 목표:

* HTML 구조 이해
* CSS 레이아웃 구성
* 버튼, 카드, 메뉴 등 UI 제작
* 반응형 웹 기초 학습
* GitHub Pages 또는 Vercel 배포 경험

## 6. 프로젝트 진행 방식

1. 아이디어 회의
2. 자료 조사
3. 기능 정리
4. 역할 분담
5. 개발 진행
6. 오류 수정
7. 결과물 정리
8. 발표 자료 제작
9. 최종 피드백
10. README 및 문서 정리

---

## 7. 협업 규칙

* 작업 전 현재 진행 상황을 확인합니다.
* 수정한 내용은 간단하게 기록합니다.
* 파일명은 알아보기 쉽게 작성합니다.
* 회의 내용은 회의록으로 정리합니다.
* 프로젝트별 README를 작성합니다.
* 오류가 발생하면 해결 과정도 함께 기록합니다.
* 완성된 결과물뿐만 아니라 과정도 중요하게 정리합니다.

---

## 8. 커밋 메시지 예시

```bash
feat: 챗봇 기본 응답 기능 추가
fix: 게임 점수 계산 오류 수정
docs: 회의록 내용 추가
style: 웹페이지 CSS 수정
refactor: 코드 구조 정리
add: 공모전 아이디어 자료 추가
```

---

## 9. 기대 효과

이 저장소를 통해 동아리 활동 내용을 한눈에 확인할 수 있고, 프로젝트별 진행 과정과 결과물을 체계적으로 관리할 수 있습니다.

또한 GitHub 협업 방식에 익숙해지고, 공모전과 개발 프로젝트 경험을 쌓으면서 개인 포트폴리오로도 활용할 수 있습니다.

* 동아리 프로젝트 기록 꾸준히 관리
* 공모전 참여 경험 확대

* 팀원 간 협업 능력 향상
* GitHub 사용 능력 향상
* 후배들도 참고할 수 있는 자료로 발전
